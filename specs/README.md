# Specs

Pinned copies of upstream API descriptions, used to generate and check types. Each belongs to its publisher and keeps its own licence, which is separate from this repository's.

| Directory | Source | Licence |
|---|---|---|
| `github/` | [github/rest-api-description](https://github.com/github/rest-api-description) | MIT |
| `osv/` | [ossf/osv-schema](https://github.com/ossf/osv-schema) | Apache-2.0 |
| `daytona/` | [Daytona API docs](https://www.daytona.io/docs/openapi.json) | Apache-2.0, per each spec's `info.license` |

Example credentials inside these files are upstream's documentation samples.
